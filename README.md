# منصة المساعد القانوني الافتراضي

مشروع تعليمي بواجهة عربية باستخدام Python وFlask وHTML/CSS/JavaScript.
يضم ست خدمات: الاستشارة، صياغة العقود، المذكرات، تحليل المذكرات، الاعتراضات، والمحادثة.
المخرجات استرشادية وليست بديلًا عن محامٍ مختص.

## التشغيل المحلي

يتطلب Python 3.10 أو أحدث:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

افتح http://127.0.0.1:5000 . تظهر الواجهة دون مفتاح، لكن توليد الإجابات يتطلب إعداد Gemini.

## إعداد الذكاء الاصطناعي

انسخ `.env.example` إلى `.env` وأضف مفتاح حسابك ومعرّف نموذج متاح لحسابك.
يقرأ التطبيق الملف محليًا، أو يستخدم متغيرات البيئة المضبوطة على الخادم.
لا تضع المفتاح داخل الكود أو GitHub. ملف `.env` مستثنى من Git.
حذف مفتاح سبق نشره من الكود الحالي لا يزيله من سجل Git السابق.

## بنية المشروع

- `app.py`: نقطة التشغيل.
- `services/`: تطبيق الويب والخدمات.
- `legal_advisor/`: توجيه الطلبات.
- `prompts/`: تعليمات النموذج.
- `config/`: أسماء الخدمات والتنبيهات.
- `templates/`: واجهة الويب.
- `tests/`: اختبارات تعمل دون إرسال بيانات إلى Gemini.

## الاختبار

```powershell
python -m unittest discover -s tests -v
```

هذه نسخة للعرض كمشروع تعليمي والتشغيل المحلي. قبل تشغيل خدمة عامة أضف التحكم في الوصول وحدود الاستخدام لحماية رصيد API.
